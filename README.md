# TrafficAI — AI-Based Intelligent Traffic Management Agent

Academic AI intelligent-agent prototype demonstrating **Sense → Analyze → Decide → Act**.

## Features
- TrafficAI command-center dashboard
- Live telemetry simulation
- Traffic-state classification
- Goal-based decision agent
- Emergency-priority scenario
- PEAS-aligned architecture
- Optional OpenCV video-processing module
- Flask backend + HTML/CSS/JavaScript frontend

## Run
See `SETUP_WINDOWS.txt`.

Open: `http://127.0.0.1:5000`

## Important
This is an academic prototype. Traffic values and actuator actions are simulated/digitally represented; it is not connected to physical city traffic infrastructure.
